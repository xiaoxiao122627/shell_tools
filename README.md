## Shell 运维工具库

**作者**：Jasyn  
**时间**：2026.07 - 2026.08  
**语言**：Bash  
**适用系统**：Linux / Unix

### 项目简介

本仓库是实习期间为提升日常运维效率而编写的 Shell 脚本工具集。脚本覆盖了**交互式输入、参数处理、文件检测、信息采集、系统监控**等常见运维场景，所有脚本均已在 Ubuntu 18.04 环境下测试通过。

### 脚本列表

| 序号 | 脚本名称 | 功能描述 | 使用方式 |
| :---: | :--- | :--- | :--- |
| 1 | `hello.sh` | 交互式脚本，接收用户输入并打印问候语 | `./hello.sh` |
| 2 | `prevar.sh` | 参数测试，打印脚本名、参数个数、全部入参 | `./prevar.sh arg1 arg2 ...` |
| 3 | `calculate.sh` | 简易计算器，接收2个数字实现加减乘除 | `./calculate.sh 8 2` |
| 4 | `check_dir.sh` | 检测目录是否存在，不存在则自动创建 | `./check_dir.sh` |
| 5 | `score_degree.sh` | 根据成绩输出等级（优秀/良好/及格/不合格） | `./score_degree.sh` |
| 6 | `menu.sh` | 交互式菜单，查看磁盘/内存/系统运行时间 | `./menu.sh` |
| 7 | `ping_test.sh` | 批量 Ping 测试，检测多台主机连通性 | `./ping_test.sh` |
| 8 | `system_info.sh` | 收集主机基础信息（主机名/系统版本/内存/磁盘） | `./system_info.sh` |
