# Shell 运维工具库 (shell_tools)

## 项目简介
本仓库是作者在 **广州亚信技术有限公司** 担任系统运维实习生期间，为提升生产环境日常运维效率而开发的脚本工具集。所有脚本均遵循统一规范，并在生产环境中得到验证。

## 核心工具列表
| 脚本名称 | 功能描述 | 应用场景 |
| :--- | :--- | :--- |
| `disk_monitor.sh` | **磁盘使用率监控告警** | 通过 `df -h` 采集数据，使用 `awk` 提取使用率，超阈值（如80%）时触发告警并记录日志。 |
| `log_archiver.sh` | **业务日志自动备份** | 按周期压缩归档业务系统日志，释放磁盘空间，防止日志撑爆根分区。 |
| `process_checker.sh` | **关键进程存活检测** | 定时检测核心服务进程，若进程异常退出则自动重启并发送告警。 |
| `system_info.sh` | 服务器基础信息收集 | 快速收集主机名、操作系统版本、内存、磁盘等信息，用于资产盘点或故障定位。 |
| `batch_ping.sh` | 批量主机连通性测试 | 通过循环和 `ping` 命令，快速检测多台服务器的网络连通状态。 |

## 使用规范
所有脚本均采用统一的 `log()` 函数进行日志输出，格式为 `[时间戳] 内容`，支持同时输出至控制台和日志文件，便于操作审计。

## 运行环境
*   OS: CentOS 7 / Ubuntu 18.04+
*   Shell: Bash
